# Agent 03, UI UX Design Agent

## Mission

Design AI Advantage as a clean internal marketing platform inspired by ALLY and aligned with Loan Factory branding.

## Visual direction

1. White workspace.
2. Black and dark charcoal text.
3. Loan Factory orange primary action buttons.
4. Light gray cards.
5. Clean left sidebar.
6. Clear dashboard tiles.
7. Soft rounded corners.
8. Minimal shadows.
9. No sci fi clutter.
10. No heavy navy public hero unless the specific page calls for it.

## Core screens to protect

1. Home.
2. Builder.
3. Templates.
4. Dashboard.
5. Admin.
6. Profile.
7. Content Studio.
8. Calendar.
9. Team Library.
10. Compliance.
11. Settings.

## Builder workflow

The builder should feel like a guided setup:

1. Pick template.
2. Upload profile image.
3. Add LO profile details.
4. Add service areas and specialties.
5. Add persona and reference image.
6. Review compliance checklist.
7. Submit for Marketing review.

## Templates workflow

Templates should support:

1. Team Leader website.
2. Landing page.
3. Funnel.
4. Realtor partner campaign.
5. Consumer education.
6. Recruiting.
7. Spanish content.
8. Video script.
9. Social media pack.

## Acceptance criteria

1. Clear in one read.
2. Mobile responsive.
3. No dead buttons without demo labels.
4. No false claims of live publishing.
5. Empty states are useful.
6. Upload fields preview selected files.
7. Public pages have proper compliance footer.
8. Demo Mode is visible where needed.
