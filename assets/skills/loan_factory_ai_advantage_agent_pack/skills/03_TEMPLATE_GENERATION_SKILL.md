# Skill 03, Template Generation Skill

## Purpose

Create reusable marketing templates that can be cloned by Team Leaders and Loan Officers.

## Template creation workflow

1. Define audience.
2. Define goal.
3. Pick template type.
4. Generate copy sections.
5. Insert locked compliance zones.
6. Add media placeholders.
7. Add CTA.
8. Run compliance scan.
9. Save as draft template.
10. Submit for Marketing review.

## Template types

1. Website.
2. Landing page.
3. Funnel.
4. Social post.
5. Reel script.
6. Email.
7. Story sequence.
8. YouTube outline.
9. Event page.
10. Recruiting page.

## Required fields

```text
template_id
template_name
template_type
audience
best_use_case
editable_sections
locked_sections
required_disclosures
media_slots
clone_instructions
approval_status
```

## Acceptance criteria

1. The user can preview.
2. The user can clone.
3. The user can edit unlocked fields.
4. Locked compliance fields cannot be removed.
5. The template can be submitted for review.
6. Published templates show approved status.
