# AI Boardroom Usage Notes

## What this boardroom does

The AI Boardroom is a pressure testing system. It is not meant to impersonate public figures or copy their content. It uses strategic lenses such as scale, offer design, audience psychology, research, evidence, systems, and execution discipline.

## How to use it inside AI Advantage

Use the boardroom as an internal review layer for:

1. Homepage positioning.
2. Template library structure.
3. Team Leader onboarding.
4. Content strategy.
5. Social posts.
6. Video scripts.
7. YouTube ideas.
8. Landing pages.
9. Recruiting campaigns.
10. Realtor partner campaigns.
11. Compliance sensitive marketing.

## Recommended review flow

1. Chief Orchestrator receives the task.
2. Brand Compliance Agent checks the hard guardrails.
3. Market Research Agent checks audience and competitor context.
4. UI UX Agent checks usability.
5. SEO GEO AEO Agent checks findability.
6. Content Strategy Agent checks message clarity.
7. YouTube Research Agent checks video and audience angle when needed.
8. AI Twin Agent adapts the final copy to Jeremy or the selected Loan Officer.
9. Chief Orchestrator produces the final action plan.

## Do not do this

1. Do not publicly claim a response is written by or endorsed by a real public figure.
2. Do not copy copyrighted phrasing or voice too closely.
3. Do not override compliance rules for better engagement.
4. Do not publish generated marketing without approval.
5. Do not use the boardroom to invent facts, rates, lending terms, or Loan Factory policy.

## Output standard

Every agent should return:

1. Summary.
2. Verdict.
3. Priority fixes.
4. Risks.
5. Recommended next action.
